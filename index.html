Lab Drive (rclone)

A personal storage integration operated by Jincheng Gao. It uses rclone to access the owner’s Google Drive from a Linux research server, allowing infrequently used files to be archived and retrieved.

The integration is for the owner’s personal use. Google Drive access requires the account owner’s explicit OAuth authorization.

This website contains documentation only. It does not provide access to files stored in Google Drive.
